Baza ilə əlaqə qurulmadı

Supabase layihəsinə qoşulmaq mümkün olmadı. Zəhmət olmasa konfiqurasiyanı yoxlayın.

  1. assets/js/config.js faylında SUPABASE_URL və publik açarın düzgün olduğunu yoxlayın.
  2. Supabase → SQL Editor bölməsində supabase/schema.sql faylını işə salın.
  3. Supabase layihəsinin paused (dayandırılmış) olmadığını yoxlayın.

Texniki detallar brauzer konsolunda göstərilir.
